# Submission requirements and evidence plan

The supplied course evaluation deck (19 October 2026) and course-report grading
form specify seven assessment criteria. The A band is 19–20 for a 20-point item
and 10 for a 10-point item. This document maps evidence; it assigns no grade.

| Criterion | Points | Required evidence in this project |
|---|---:|---|
| Topic selection | 20 | A bounded, practically useful reliability question and explicit user workflow |
| Literature application | 10 | Verified 2024–2026 primary sources, comparative synthesis and traceable design decisions |
| Research and investigation | 20 | Frozen extension protocol, independent oracle, controlled ablations, public data, raw model outputs and paired analysis |
| Report format | 10 | Supplied SCU layout, official supplied university wordmark, English labels, correct captions, citations and bibliography |
| Report quality | 20 | Clear research questions, sufficient implementation detail, actual outcomes, error taxonomy and limitations |
| Innovation | 10 | Measured separation of schema validity from factual consistency and portable verification evidence |
| Workload and attitude | 10 | Working code, meaningful tests, reproducible commands, coherent commits and a prepared demonstration |

The course permits any AI tools for code, report and slides and requires individual
delivery. It recommends GitHub. The course document is due in December 2026; no
exact day appears in the supplied deck.

Overall course weights are attendance/participation 30%, final project 50% and
documentation 20%. The final project includes PPT/project description 25% and
report 25% of the course. A separate assessment breakdown gives presentation 20%,
peer evaluation 20% and instructor evaluation 60%. These schemes are recorded
separately, because the documents do not explain how to combine them.

## Report format retained from the supplied template

- A4, 2.5 cm side margins, 2.75 cm top and 3 cm bottom.
- 12-point body text, 1.5 line spacing and a two-em first-line indent.
- Centered major headings and section-based figure, table and equation numbering.
- Course header, centered page number, booktabs tables and GB/T 7714 references.
- An English cover using the supplied SCU wordmark, student/course/instructor fields
  and academic term. The submission copy includes the student number. Public
  source uses a local ignored identity file for that field.

The Chinese template is a formatting source. All authored report and slide text
remains English; the official university artwork retains its original lettering.
Lecturer-owned grading files are not redistributed.
